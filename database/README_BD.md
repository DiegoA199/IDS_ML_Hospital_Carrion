# Base de datos relacional IDS-ML

Este directorio contiene el modelo relacional académico del sistema IDS-ML para una red institucional hospitalaria.

## Archivos

- `schema.sql`: crea 62 tablas relacionales con claves primarias, claves foráneas, estados y marcas de tiempo.
- `seed_demo.sql`: carga datos demostrativos no sensibles.
- `init_db.py`: inicializa una base SQLite local.

## Crear la base SQLite

```powershell
py -3 database/init_db.py --db idsml_relational.db
```

Para crear solo estructura:

```powershell
py -3 database/init_db.py --db idsml_relational.db --no-seed
```

## Ejecutar manualmente en SQLite

```powershell
sqlite3 idsml_relational.db ".read database/schema.sql"
sqlite3 idsml_relational.db ".read database/seed_demo.sql"
```

## Abrir en SQLiteStudio o DBeaver

1. Abra SQLiteStudio o DBeaver.
2. Seleccione `Agregar base de datos`.
3. Elija el archivo `idsml_relational.db`.
4. Explore tablas, claves foráneas y datos demo.

## Adaptación a PostgreSQL

El diseño ya tiene una versión PostgreSQL en `database/postgresql/`.

Con Docker:

```powershell
copy .env.example .env
docker compose up --build
```

Después abra Adminer en `http://localhost:8080` para ver tablas y datos.

Si se adapta manualmente:

- reemplazar `INTEGER PRIMARY KEY AUTOINCREMENT` por `BIGSERIAL PRIMARY KEY` o `GENERATED BY DEFAULT AS IDENTITY`;
- reemplazar `TEXT` por `VARCHAR(n)`, `TIMESTAMP` o `JSONB` cuando corresponda;
- mantener las mismas claves foráneas y restricciones `UNIQUE`;
- ejecutar migraciones con Alembic/Flyway si el proyecto crece.
