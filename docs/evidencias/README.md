# Evidencias graficas IDS-ML

Esta carpeta contiene imagenes listas para anexar en el informe de tesis, sustentacion o documentacion tecnica del prototipo IDS-ML.

| Archivo | Uso recomendado |
|---|---|
| `sonarqube_quality_gate.png` | Evidencia visual de Quality Gate, metricas SonarCloud y GitHub Actions. |
| `base_datos_60_tablas.png` | Resumen visual del modelo relacional: 60 tablas formales y 8 tablas operativas. |
| `base_datos_listado_60_tablas.png` | Listado visual de las 60 tablas academicas del esquema PostgreSQL. |
| `proceso_hospital_ids_ml_bpmn.png` | Diagrama conceptual tipo Bizagi/BPMN del proceso hospitalario IDS-ML. |
| `orientacion_iso_nist_ids_ml.png` | Relacion del prototipo con ISO/IEC 27001, ISO/IEC 25010 y NIST CSF. |

Estas imagenes no reemplazan la validacion funcional, pero ayudan a presentar evidencia clara sobre calidad del software, base de datos fisica, procesos institucionales y alineacion con normas.
