# Evidencias graficas IDS-ML

Esta carpeta contiene dos tipos de material:

1. `docs/evidencias/reales/`: capturas y archivos reales obtenidos desde SonarCloud, GitHub Actions, Adminer/PostgreSQL y la aplicacion Streamlit.
2. Imagenes explicativas ubicadas directamente en esta carpeta: laminas referenciales para resumir Sonar, base de datos, procesos e ISO/NIST.

Para evidencia formal de tesis, use primero los archivos de `docs/evidencias/reales/`.

| Archivo | Uso recomendado |
|---|---|
| `reales/` | Evidencias reales capturadas desde herramientas y servicios vinculados. |
| `sonarqube_quality_gate.png` | Evidencia visual de Quality Gate, metricas SonarCloud y GitHub Actions. |
| `base_datos_60_tablas.png` | Resumen visual del modelo relacional: 60 tablas formales y 8 tablas operativas. |
| `base_datos_listado_60_tablas.png` | Listado visual de las 60 tablas academicas del esquema PostgreSQL. |
| `proceso_hospital_ids_ml_bpmn.png` | Diagrama conceptual tipo Bizagi/BPMN del proceso hospitalario IDS-ML. |
| `orientacion_iso_nist_ids_ml.png` | Relacion del prototipo con ISO/IEC 27001, ISO/IEC 25010 y NIST CSF. |

Las imagenes referenciales no reemplazan la validacion funcional ni las capturas reales. Sirven para explicar el proyecto, pero no deben presentarse como capturas externas de una herramienta.
