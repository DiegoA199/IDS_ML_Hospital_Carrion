# Pruebas funcionales

## Objetivo

Validar desde la perspectiva del usuario que las funciones reales del IDS-ML cumplen su propósito.

## Escenarios base

- Autenticación y navegación según rol.
- Carga y perfilado de un CSV válido.
- Preparación y entrenamiento de modelos.
- Comparación de métricas y selección del mejor modelo.
- Predicción de tráfico y creación de alertas.
- Consulta de historial y descarga de reportes.

## Evidencia

Registrar código del caso, fecha, responsable, resultado obtenido y captura sin datos sensibles. Los mockups son referencia visual y no sustituyen una ejecución funcional.
