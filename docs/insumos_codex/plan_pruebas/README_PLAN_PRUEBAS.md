# Plan de pruebas interno

Esta carpeta contiene insumos internos para planificar y documentar la calidad del IDS-ML. No debe aparecer como módulo visual ni agregarse al menú de Streamlit.

## Propósito

- Guiar pruebas unitarias, de integración, funcionales, de seguridad y rendimiento.
- Mantener trazabilidad entre casos, resultados esperados y evidencias.
- Facilitar la revisión académica y técnica sin mezclar documentación con funciones de producción.

## Uso

La matriz `matriz_plan_pruebas.csv` contiene el inventario base. Los documentos por tipo describen alcance y criterios de ejecución. Las capturas, reportes y resultados autorizados se guardan en `evidencias/`, evitando información sensible o tráfico hospitalario real.
