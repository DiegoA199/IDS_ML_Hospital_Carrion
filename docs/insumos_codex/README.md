# Insumos internos para Codex y tesis

Esta carpeta reúne materiales de referencia que apoyan el desarrollo, la validación y la documentación académica del IDS-ML.

- `mockups/`: referencias visuales exportadas desde Stitch.
- `plan_pruebas/`: matrices y guías internas de verificación.
- `estado_arte_implementacion/`: artículos y fichas que sustentan decisiones de implementación.

Estos contenidos no son módulos funcionales de Streamlit y no deben incorporarse al menú de la aplicación desplegada.
