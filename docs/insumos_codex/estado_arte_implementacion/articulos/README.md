# Artículos seleccionados

Esta carpeta contiene los 12 PDF proporcionados como insumo para implementar y mejorar el IDS-ML. Los nombres fueron normalizados con el código académico como prefijo y coinciden con `matriz_estado_arte_implementacion.csv`.

## Uso

- Consultar primero los artículos de prioridad principal descritos en `../seleccion_articulos.md`.
- Utilizar los documentos como sustento técnico y académico, no como requisitos automáticos de producto.
- Registrar en las fichas qué decisión concreta del IDS-ML respalda cada artículo.
- No exponer los PDF ni esta carpeta mediante la interfaz Streamlit.
- Conservar en el repositorio únicamente documentos cuya licencia o autorización permita su almacenamiento.
