# Estado del arte de implementación de software

Esta carpeta no reemplaza el estado del arte general de la tesis. Reúne únicamente referencias que ayudan a implementar, evaluar y mantener mejor el producto software IDS-ML.

## Criterios de uso

- Los artículos deben aportar a arquitectura, procesamiento, evaluación, interpretabilidad, despliegue o herramientas de implementación.
- Los PDF autorizados deben guardarse en `articulos/` respetando licencias y derechos de autor.
- Las fichas resumidas deben guardarse en `fichas_individuales/` e indicar la relación concreta con el proyecto.
- `matriz_estado_arte_implementacion.csv` mantiene la trazabilidad académica de las referencias.
- `seleccion_articulos.md` distingue las referencias principales de las complementarias.
- `resumen_aportes.md` consolida los aportes por tema de implementación.

La información es insumo para Codex y evidencia académica. No es una pantalla ni un módulo visible de la aplicación.
